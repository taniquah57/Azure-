2. Least Privilege RBAC
 
   Assigned Azure roles based on each user's job responsbilities:
   
   • Jasmine - Reader
   
   • Matthew - Role Based Access Control Administrator
   
   • Tasha - Contributer
   
This provided least privilege by ensuring users only received the permissions necessary to perform their job responsibilities.
